# دفتر الحصص — تطبيق PWA

جدول مدرسي وجدول دروس خصوصية، يعمل بالكامل بدون إنترنت بعد أول فتح، وقابل للتثبيت على الموبايل زي أي تطبيق عادي.

## هل البيانات محلية؟

نعم. كل البيانات (الفصول، البطاقات، الجدول) بتتخزن جوه المتصفح نفسه على جهازك (`localStorage`)، مفيش أي سيرفر أو اتصال إنترنت مطلوب لحفظ أو عرض بياناتك. الإنترنت مطلوب مرة واحدة بس أول ما تفتح الرابط لأول مرة (عشان يحمّل الخطوط وملفات التطبيق)، وبعدها الصفحة تفضل شغالة أوفلاين تمامًا حتى لو قفلت النت.

⚠️ ملحوظة مهمة: `localStorage` بيفضل موجود طول ما متمسحش بيانات المتصفح (Clear browsing data) يدويًا. للأمان، استخدم زر **"نسخة احتياطية"** بانتظام عشان تنزّل ملف JSON فيه كل بياناتك، وترجّعه وقت ما تحب بزر **"استرجاع نسخة"** — ده أضمن حل حتى لو غيّرت الموبايل أو مسحت المتصفح.

## النشر على GitHub Pages (مجانًا)

1. اعمل Repository جديد على GitHub (مثلاً `jadwal-hisas`).
2. ارفع الملفات دي كلها في جذر الـ Repository:
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - مجلد `icons/` بكل اللي فيه
3. من إعدادات الـ Repository: **Settings → Pages** → اختار الفرع `main` والمجلد `/root` → Save.
4. بعد دقيقة أو اتنين، هيديك GitHub رابط زي:
   `https://username.github.io/jadwal-hisas/`
5. افتح الرابط من موبايلك (متصفح Chrome أو Safari).

## تثبيت التطبيق على الموبايل (كأيقونة على الشاشة الرئيسية)

**Android (Chrome):**
افتح الرابط → هيظهر إشعار "إضافة إلى الشاشة الرئيسية" تلقائيًا، أو من قائمة المتصفح (⋮) اختار **"تثبيت التطبيق"**.

**iPhone (Safari):**
افتح الرابط → زر المشاركة (Share) → **"إضافة إلى الشاشة الرئيسية"** (Add to Home Screen).

بعد التثبيت، هتلاقي أيقونة دفتر الحصص على شاشتك زي أي تطبيق عادي، وهتفتح بدون شريط عنوان المتصفح، وتشتغل أوفلاين بالكامل.

## الملفات

```
index.html          الصفحة الرئيسية (كل الكود والتصميم)
manifest.json        بيانات التطبيق (الاسم، الأيقونة، الألوان)
service-worker.js    مسؤول عن التخزين المؤقت والعمل أوفلاين
icons/icon-192.png   أيقونة صغيرة
icons/icon-512.png   أيقونة كبيرة (لشاشات الدقة العالية)
```
